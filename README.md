# WildGuard — Discrete Maths for Nilgiri Elephant Corridors

Live site: open the GitHub Pages link for this repository.

This website runs the project's real Python code (`py/maths.py`, `py/app.py`) **inside the browser** using Pyodide. No server is needed.
The first visit takes about 10 seconds while Python loads. Data you enter is saved only in your own browser (add `?fresh` to the URL to start clean).

Full project with the Flask version, tests and presentation guide: see the original project folder.
