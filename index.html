Why this project

A blocked corridor doesn't stop elephants. It sends them into villages.

Elephants must keep moving between forests for food and water. When their corridor is cut by a fence, road, canal or power line, they detour through farms, railway lines and homes. That is where people and elephants die.

The everyday problem

  • Which reports are real? Many are rumours or days old.
  • Which blockage hurts most? Some corridors have a detour; some are the only way through.
  • Who goes where, and when? Nobody should be overloaded, and proof needs camera, patrol and night-watch records from the same time.

Module 01 · Propositional logic & truth tables

Should this report be treated as urgent?

Four yes/no facts about a report are combined with AND. Only when all four are true does it go to urgent human review.

1

The maths

Each condition is a proposition with value 1 (true) or 0 (false). The conjunction ∧ is true only when every operand is true.

Module 02 · Number theory: GCD & LCM

When will all monitoring checks happen at the same time?

Camera traps, foot patrols and night watch run on different repeating intervals. The LCM tells us when they line up for a joint verification; Euclid's algorithm gives the GCD it needs.

1

The maths

Euclid's algorithm repeats division with remainder until the remainder is 0. The last non-zero remainder is the GCD. The LCM then follows from it.

a = q·b + r ⇒ gcd(a, b) = gcd(b, r)repeat until r = 0
lcm(a, b) = (a × b) ÷ gcd(a, b)for three schedules: lcm(a, b, c) = lcm(lcm(a, b), c)

In the field. A sighting counts as proven only when camera-trap footage, patrol notes and the night-watch log cover the same moment. Number theory finds when that happens.

A report can only be verified when camera footage, patrol notes and night-watch logs exist for the same minute. That happens every L = lcm(intervals) minutes. Each team verifies one report per joint checkpoint, so its k-th report is verified at shift start + k·L.

Module 03 · Relations & Warshall's algorithm

Can an elephant still get from one reserve to another?

"Directly linked" is a relation R on the set of reserves. Its transitive closure R* answers "linked through any chain of corridors". Block a link and see whether the answer changes.

1

The maths

R is stored as a 0/1 matrix M. Warshall's algorithm allows one more intermediate vertex k at each stage. After all n stages the matrix is R*.

Wk[i][j] = Wk−1[i][j] ∨ (Wk−1[i][k] ∧ Wk−1[k][j])W₀ = M (direct links plus reflexive pairs), Wₙ = R*

In the field. A blockage matters because of the journeys it stops, like Moyar to Singara or Kaniyanpura to Segur. Warshall's algorithm counts every journey that is lost.

For each reported corridor e, R* is computed for G and for G − e. The difference |R*(G)| − |R*(G − e)| is the number of reserve pairs elephants could no longer travel between. This is the third priority key: a report that threatens more routes goes first.

Module 04 · Partial orders & lattices

How complete is the evidence, and what is still missing?

A report can carry four kinds of evidence. All possible evidence sets, ordered by ⊆, form a lattice. Where a report sits in it tells us exactly what to collect next.

1

The maths

(P(E), ⊆) is a partial order: reflexive, antisymmetric and transitive. It is a lattice because any two sets have a join (∪) and a meet (∩).

Module 05 · Functions & the pigeonhole principle

How many reports must the busiest field team handle?

Assigning every pending report to one team is a function f : Reports → Teams. The pigeonhole principle gives a load no assignment can beat.

1

The maths

If n reports go into m teams, at least one team receives at least ⌈n/m⌉ reports. f can be one-to-one only when n ≤ m, and onto only when n ≥ m.

max load ≥ ⌈ n / m ⌉n = q·m + r ⇒ r teams get q + 1 reports, the rest get q

In the field. With three teams and seven reports, someone has to handle more than two. The pigeonhole principle gives the minimum, and WildGuard's assignment reaches it.

Reports are taken in priority order and each goes to the least-loaded available team. That defines f : Reports → Teams. The pigeonhole bound ⌈n/m⌉ is the number of joint checkpoints the busiest team needs, so the queue cannot be cleared sooner than ⌈n/m⌉ · L minutes.

Module 06 · Graphs, subgraphs & bridges

Which corridor, if lost, would split the network?

Removing an edge gives the subgraph G − e. If G − e has more connected components than G, that corridor is a bridge and is the highest priority to verify.

1

The maths

An edge e is a bridge when c(G − e) > c(G), where c counts connected components. A connected graph with |E| = |V| − 1 is a tree, and in a tree every edge is a bridge.

Σ deg(v) = 2|E|handshaking lemma: each edge adds 1 to the degree of both its ends
e is a bridge ⇔ c(G − e) > c(G)

In the field. If a fence blocks a corridor that has a detour, elephants walk around it. If it is the only link, the herd is trapped. That only link is a bridge.

For every reported corridor, WildGuard checks whether c(G − e) > c(G). A report on a bridge corridor is ranked above one on a corridor that has an alternative route, because losing a bridge cuts reserves off completely.
